# Проект автоматизации тестов для сервиса Stellar Burgers
1. Основой для автотестов послужили pytest 8.4.2 и selenium 4.36.0
2. Команда для запуска тестов - pytest -v
3. В names.py перечислил рандомные имена пользователей
4. В conftest.py собраны все фикстуры
5. В папке tests лежат на октябрь 2025:
    test_constructor_section - тесты по "конструктору" бургера
    test_login_page - тесты по кнопке "Войти в аккаунт", "Личный кабинет", "Зарегистрироваться" и "Восстановить пароль"
    test_private_page - тесты по личному кабинету
    test_registration_page - тесты по регистрации (поле Пароль)
6. В data.py лежит существующие в базе логин и пароль
7. В locators.py собраны все элементы с сервиса
8. В urls.py собраны все используемые адреса
